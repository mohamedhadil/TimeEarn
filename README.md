⏳ Earn Screen Time

Complete your tasks. Earn your screen time. Build better habits.

Earn Screen Time is a productivity-focused Android application designed to encourage users to manage their daily tasks and reduce unnecessary screen time.

Instead of scrolling endlessly, users can complete their planned tasks, earn entertainment time, and monitor their app usage.

---

✨ Features

📋 Task Management

- Create and manage daily tasks.
- Track task completion.
- Monthly calendar with task completion indicators.
- Organize daily activities.

⏱️ Productivity Timer

- Built-in countdown timer.
- Start, pause and resume functionality.
- Track dedicated productivity sessions.
- Persistent timer notifications.

🎁 Earn Screen Time

- Complete tasks to earn entertainment time.
- Connect productivity with recreational screen time.
- Encourage a more balanced digital routine.

📱 App Usage Tracking

- Monitor daily usage of selected applications.
- View individual app usage statistics.
- Set daily usage limits for individual apps.
- Track remaining time using progress indicators.

🔔 Native Android Integration

- Foreground timer service.
- Persistent timer notifications.
- Android Usage Stats integration.
- Local data persistence.

🚀 Project Status

Development Status: Active Development

This project started as a web-based productivity application and was subsequently developed into an Android application with native Android functionality.

The application is currently maintained as a GitHub-hosted personal project and is not yet published on the Google Play Store or Apple App Store.

---

🎯 Project Objective

The main objective of this project is to explore a productivity-based approach to screen-time management.

It aims to encourage users to prioritize their responsibilities while maintaining a healthy balance between productivity and entertainment.
